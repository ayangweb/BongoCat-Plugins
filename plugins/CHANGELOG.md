# Plugin Changelog

## 1.0.0 - 2026-10-17

### com.bongocat.input-source

#### ✨ Features

- Added an indicator that shows the current input source icon and name.
- Added always-show and show-after-switch display modes.

### com.bongocat.key-sounds

#### ✨ Features

- Added customizable sounds for keyboard and mouse button presses and releases.
- Added volume (default 100), per-device sound-set selection, and built-in sound sets.

### com.bongocat.pomodoro

#### ✨ Features

- Added a focus timer with configurable durations from 1 to 180 minutes.
- Added start, pause, and restart controls with persistent timer state.
